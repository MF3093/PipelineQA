## Task Board — Drag and Drop Constraints

The following constraints apply to the drag-and-drop feature:

- Cards can only be dragged within the same board (no cross-board moves).
- The board has four fixed columns: To Do, In Progress, In Review, Done.
- Drag is initiated only with mouse button 1 (left click hold).
- Touch drag is not supported in the current sprint.

## Column Transition Rules

| From | To | Allowed? |
|------|----|----------|
| To Do | In Progress | Yes |
| To Do | Done | No — must pass through In Progress and In Review |
| In Progress | In Review | Yes |
| In Review | Done | Yes |
| Done | Any | No — completed cards are locked |
