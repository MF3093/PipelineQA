System-Wide Glossary and Design Constraints

This document applies to ALL stories in the project.

Key Terms

  • Active: A record currently in operational use.
  • Draft: A record saved but not yet submitted for processing.
  • Archived: A record removed from active view but retained for audit.

Global Constraints

  • Maximum file upload size: 10 MB for all features.
  • Session timeout: 30 minutes of inactivity.
  • Date format: DD/MM/YYYY across all forms.
  • All user-facing error messages must be plain English (no technical codes).

Accessibility Requirements

All interactive elements must meet WCAG 2.1 AA standards. Tab order must follow visual reading order.
